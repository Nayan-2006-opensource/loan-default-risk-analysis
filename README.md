# Loan Default Risk Analysis

## 📌 Project Overview

This project analyzes personal loan data to identify patterns and factors associated with loan default risk.

The project follows an end-to-end data analytics workflow, from raw data assessment and cleaning to exploratory data analysis and business insights.

---

## 🎯 Project Objective

The objective of this project is to analyze personal loan data and identify customer and financial factors associated with a higher risk of loan default.

---

## 📊 Dataset

The dataset contains information related to personal loans and borrower characteristics.

The raw dataset is stored in the `data` directory.
